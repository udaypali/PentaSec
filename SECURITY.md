# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Email:** udaypali134@gmail.com

Please include:
- A description of the vulnerability
- Steps to reproduce (if applicable)
- Potential impact
- Any suggested fixes (optional)

We will respond as soon as possible and work with you to address the issue.

## Supported Versions

We currently provide security updates for the latest release only.

## Security Best Practices

- Keep your dependencies up to date
- Use the latest version of this project
- Report any suspicious activity or potential security issues promptly
